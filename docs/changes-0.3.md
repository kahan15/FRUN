# Version 0.3 — release preparation

- In-app account deletion with password confirmation, backend throttling, atomic removal of active personal records and revocation of every session. Other runners' earned land remains, with identifying history references scrubbed.
- Durable deletion intent and completion lookup recover a lost response after credentials have been revoked. Local runs are erased only after confirmation; cleanup can resume after a crash. Account/server isolation and identity checks prevent an unrelated account from being erased.
- Privacy screen available before registration and from the profile; bundled Apple privacy manifest. Public policy/support configuration remains unfilled pending owner approval and publication.
- Release build phase rejects missing or local API addresses, placeholder bundle IDs, missing team/policy/support settings, unsupported SDK and unverified push enablement. Debug stays laptop-local.
- Request logs use route templates; Docker disables raw Uvicorn access logs, avoiding device tokens and search terms in normal logs.
- Migration 0003, regenerated OpenAPI and Xcode project, 8 new backend tests, 7 new native executable checks, 2 new XCTest cases and 5 release-validator tests.
- Production roadmap records individual publishing and free/no-ads/no-paid-features decisions, with detailed owner actions and remaining engineering gates.

No enrollment, hosting, signing, public deployment or App Store submission was performed. Backup retention, restore-time deletion reconciliation, public recovery/moderation and manual UI/physical-device acceptance remain release blockers. See verification.md for exactly what ran.
